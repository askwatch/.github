**[AskWatch](https://askwatch.ai/?ref=github-profile)** is an AI visibility tracker: it shows how often ChatGPT, Perplexity, Gemini, Copilot and Google AI name your brand, where you rank in the answer, and which pages they cite.

Here we publish what anyone can use for free:

- **[AI crawlers list](https://askwatch.github.io/ai-crawlers/)**: 26 AI and search crawlers with robots.txt tokens, user agents and IP ranges, as JSON and CSV ([repo](https://github.com/askwatch/ai-crawlers))
- **[Google Search Console MCP](https://github.com/askwatch/gsc-mcp)**: docs for the free hosted MCP server that lets Claude, ChatGPT and Cursor read your Search Console data
